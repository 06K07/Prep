Coin Change
You have n coin denominations (unlimited supply of each). Print the fewest coins needed to make exactly `amount`, or -1 if it is impossible.
Input: first line "n amount", second line n distinct positive integers.
Constraints: 1 <= n <= 100, 1 <= coin <= 10^5, 0 <= amount <= 100000. Time limit: 2 sec per test.
Example: "3 11 / 1 2 5" -> 3
