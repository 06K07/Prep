Course Schedule
There are n courses numbered 0..n-1 and m prerequisites "a b", meaning course a must be completed before course b. Print YES if all courses can be completed, otherwise NO.
Input: first line "n m", then m lines each with a and b.
Constraints: 1 <= n <= 500000, 0 <= m <= 500000, 0 <= a, b < n. Time limit: 2 sec per test.
Example: "4 3 / 0 1 / 1 2 / 2 3" -> YES, and "2 2 / 0 1 / 1 0" -> NO
