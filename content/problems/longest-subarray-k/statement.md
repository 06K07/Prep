Longest Subarray With Sum K
Given an array of n integers (can be negative) and an integer k, print the length of the longest contiguous subarray whose sum equals k. Print 0 if none exists.
Input: first line "n k", second line n integers.
Constraints: 1 <= n <= 200000, |a[i]| <= 1000. Time limit: 2 sec per test.
Example: "5 3 / 1 -1 5 -2 3" -> 4
