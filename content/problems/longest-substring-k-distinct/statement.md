Longest Substring With At Most K Distinct Characters
Given a lowercase string s and an integer k, print the length of the longest substring that contains at most k distinct characters.
Input: first line "n k", second line the string s of length n.
Constraints: 1 <= n <= 200000, 1 <= k <= 26. Time limit: 2 sec per test.
Example: "5 2 / eceba" -> 3
