Merge Intervals
Given n closed intervals [l, r], merge all overlapping intervals (intervals that touch, such as [1,4] and [4,5], also merge). Print the merged intervals sorted by start, one "l r" pair per line.
Input: first line n, then n lines each with l and r.
Constraints: 1 <= n <= 100000, 0 <= l <= r <= 10^9. Time limit: 2 sec per test.
Example: "4 / 1 3 / 2 6 / 8 10 / 15 18" -> "1 6", "8 10", "15 18"
