Minimum Eating Speed
There are n piles of bananas, pile i has p[i] bananas. Each hour you pick one pile and eat up to k bananas from it (if the pile has fewer, you finish it and the hour ends). You must eat all bananas within h hours. Print the minimum integer k that works.
Input: first line "n h", second line n integers.
Constraints: 1 <= n <= 100000, n <= h <= 10^9, 1 <= p[i] <= 10^9. Time limit: 2 sec per test.
Example: "4 8 / 3 6 7 11" -> 4
