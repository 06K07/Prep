Number of Islands
You are given an R x C grid of '0' (water) and '1' (land). An island is a group of land cells connected horizontally or vertically. Print the number of islands.
Input: first line "R C", then R lines each a string of C characters.
Constraints: 1 <= R, C <= 1000. Time limit: 2 sec per test.
Example: "3 4 / 1100 / 1001 / 0011" -> 2
