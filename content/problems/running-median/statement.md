Running Median
Numbers arrive one at a time. After each number print the median of everything received so far. For an even count use the lower of the two middle values.
Input: first line n, second line n integers.
Constraints: 1 <= n <= 200000, |a[i]| <= 10^9. Print one median per line. Time limit: 2 sec per test.
Example: "5 / 5 15 1 3 2" -> 5, 5, 5, 3, 3
