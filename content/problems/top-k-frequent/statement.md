Top K Frequent Elements
Given an array of n integers and k, print the k most frequent values on one line, ordered by frequency (highest first). Break ties by smaller value first.
Input: first line "n k", second line n integers.
Constraints: 1 <= n <= 200000, |a[i]| <= 10^9, 1 <= k <= number of distinct values. Time limit: 2 sec per test.
Example: "6 2 / 1 1 1 2 2 3" -> "1 2"
